## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Multitrack Audio Recording** — Record and edit multitrack audio effortlessly, turning your ideas into professional tracks.
- **MIDI Protocol Support** — Work seamlessly with MIDI protocols to create complex musical compositions.
